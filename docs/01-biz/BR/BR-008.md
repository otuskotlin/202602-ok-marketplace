## Business Value

Пользователь может заказать проверку контрагента (продавца или покупателя) для верификации его надёжности перед сделкой, снижая риски мошенничества

## User Stories

### US-R008-1: Заказ проверки контрагента

* **As a** пользователь платформы
* **I want to** заказать проверку контрагента
* **So that** я мог убедиться в его надёжности перед сделкой

**Acceptance Criteria:**

* **AC-R008-U1-1:**
    * **Given:** Пользователь на странице профиля контрагента
    * **When:** Нажимает "Заказать проверку"
    * **Then:** Открывается форма заказа с выбором уровня проверки

* **AC-R008-U1-2:**
    * **Given:** Пользователь выбрал уровень проверки и оплатил
    * **When:** Запрос на проверку создан
    * **Then:** Статус "В_process" отображается, начинается проверка

### US-R008-2: Базовая проверка

* **As a** платформа
* **I want to** проводить базовую проверку контрагента
* **So that** предоставить пользователю базовую информацию о надёжности

**Acceptance Criteria:**

* **AC-R008-U2-1:**
    * **Given:** Заказ на базовую проверку
    * **When:** Проверка выполняется
    * **Then:** Проверяется: подтверждение email, подтверждение телефона, история регистрации

* **AC-R008-U2-2:**
    * **Given:** Базовая проверка завершена
    * **When:** Пользователь видит результат
    * **Then:** Показывается: статус верификации (подтверждён / не подтверждён), дата регистрации, история активности

### US-R008-3: Расширенная проверка

* **As a** пользователь платформы
* **I want to** заказать расширенную проверку контрагента
* **So that** получить более глубокую информацию о компании

**Acceptance Criteria:**

* **AC-R008-U3-1:**
    * **Given:** Заказ на расширенную проверку
    * **When:** Проверка выполняется
    * **Then:** Проверяется: ИНН/ОГРН, юридический адрес, руководители, учредители, судебные дела, долги в ФНС

* **AC-R008-U3-2:**
    * **Given:** Расширенная проверка завершена
    * **When:** Пользователь видит результат
    * **Then:** Показывается: выписка из ЕГРЮЛ, финансовые показатели, история судебных дел

### US-R008-4: Проверка рейтинга

* **As a** пользователь платформы
* **I want to** видеть проверку рейтинга контрагента от платформы
* **So that** оценить надёжность на основе истории сделок

**Acceptance Criteria:**

* **AC-R008-U4-1:**
    * **Given:** Контрагент имеет историю сделок на платформе
    * **When:** Проверка рейтинга
    * **Then:** Рассчитывается: процент успешных сделок, количество жалоб, среднее время доставки

## System Constraints

| Constraint | Value | Notes |
|------------|-------|-------|
| Latency (basic) | < 24 hours | Время базовой проверки |
| Latency (extended) | < 72 hours | Время расширенной проверки |
| Availability | 99% | Доступность сервиса |

## Out of Scope

- Проверка физических лиц (паспортные данные)
- Проверка кредитной истории
- Страхование сделок
