## Business Value

Покупатель может разместить запрос на покупку компонентов, чтобы продавцы могли предложить свои товары

## User Stories

### US-R003-1: Создание запроса на покупку

* **As a** покупатель (производственное предприятие, ремонтная служба)
* **I want to** разместить объявление о покупке нужных компонентов
* **So that** продавцы могут предложить свои товары

**Acceptance Criteria:**

* **AC-R003-U1-1:**
    * **Given:** Авторизованный пользователь с ролью "покупатель"
    * **When:** Заполняет форму запроса (название, описание, требуемое количество, срок)
    * **Then:** Запрос создан и доступен для продавцов

* **AC-R003-U1-2:**
    * **Given:** Покупатель создал запрос
    * **When:** Указывает требуемые характеристики (спецификация, допуски)
    * **Then:** Характеристики отображаются в запросе

* **AC-R003-U1-3:**
    * **Given:** Покупатель создал запрос
    * **When:** Указывает желаемые условия (цена, доставка)
    * **Then:** Условия отображаются в запросе

### US-R003-2: Редактирование запроса

* **As a** покупатель
* **I want to** отредактировать созданный запрос
* **So that** обновить требования к товару

**Acceptance Criteria:**

* **AC-R003-U2-1:**
    * **Given:** Покупатель имеет активный запрос
    * **When:** Изменяет количество или срок
    * **Then:** Изменения сохранены и видны продавцам

### US-R003-3: Удаление запроса

* **As a** покупатель
* **I want to** удалить запрос
* **So that** он больше не отображается для продавцов

**Acceptance Criteria:**

* **AC-R003-U3-1:**
    * **Given:** Покупатель имеет активный запрос
    * **When:** Нажимает кнопку "Удалить"
    * **Then:** Запрос удалён (скрыт) из списка

## System Constraints

| Constraint | Value | Notes |
|------------|-------|-------|
| Latency | < 1000 ms | Время сохранения запроса |
| Max description | 5000 символов | Ограничение текста |

## Out of Scope

- Шаблоны типовых запросов
- Автоматическое уведомление подходящих продавцов
- Интеграция с тендерными площадками
