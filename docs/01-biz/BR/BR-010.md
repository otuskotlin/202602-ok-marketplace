## Business Value

Корпоративные пользователи могут интегрировать платформу с их ERP-системой для автоматического обмена данными о заказах, складских остатках и заявках

## User Stories

### US-R010-1: Подключение ERP к платформе

* **As a** корпоративный пользователь
* **I want to** подключить свою ERP-систему к платформе
* **So that** автоматизировать обмен данными

**Acceptance Criteria:**

* **AC-R010-U1-1:**
    * **Given:** Пользователь в настройках интеграций
    * **When:** Выбирает тип ERP (1С, SAP, Oracle и др.)
    * **Then:** Показывается инструкция по подключению с API-ключами

* **AC-R010-U1-2:**
    * **Given:** Пользователь ввёл настройки интеграции
    * **When:** Нажимает "Подключить"
    * **Then:** Система проверяет соединение, при успехе — интеграция активна

### US-R010-2: Синхронизация каталога

* **As a** корпоративный пользователь
* **I want to** синхронизировать каталог товаров из ERP
* **So that** автоматически размещать объявления о продаже

**Acceptance Criteria:**

* **AC-R010-U2-1:**
    * **Given:** Интеграция с ERP активна
    * **When:** Настраивается синхронизация каталога
    * **Then:** Товары из ERP автоматически появляются как объявления на платформе

* **AC-R010-U2-2:**
    * **Given:** Товар продан на платформе
    * **When:** Данные передаются в ERP
    * **Then:** В ERP создаётся заказ / списывается остаток

### US-R010-3: Импорт заявок из ERP

* **As a** корпоративный пользователь
* **I want to** импортировать заявки на закупку из ERP
* **So that** автоматически создавать объявления о покупке

**Acceptance Criteria:**

* **AC-R010-U3-1:**
    * **Given:** Интеграция с ERP активна
    * **When:** Настроен импорт заявок
    * **Then:** Заявки из ERP автоматически публикуются как объявления о покупке

* **AC-R010-U3-2:**
    * **Given:** Поступает новое объявление о продаже
    * **When:** Оно соответствует заявке из ERP
    * **Then:** Заявка автоматически закрывается, в ERP передаётся предложение

### US-R010-4: Статус синхронизации

* **As a** корпоративный пользователь
* **I want to** видеть статус синхронизации
* **So that** контролировать обмен данными

**Acceptance Criteria:**

* **AC-R010-U4-1:**

## System Constraints

| Constraint | Value | Notes |
|------------|-------|-------|
| Latency | < 5000 ms | Время синхронизации |
| Availability | 99% | Доступность сервиса |
| Sync frequency | 15 min / 1 hour / daily | Настраиваемая частота |
| ERP supported | 1C, SAP, Oracle | Список поддерживаемых |

## Out of Scope

- Кастомные ERP-системы (только типовые интеграции)
- Офлайн-режим работы
- Автоматический платёж через ERP
