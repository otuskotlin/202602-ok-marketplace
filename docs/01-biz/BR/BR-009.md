## Business Value

Пользователь может приобрести расширенный профиль, который скрывает конфиденциальную информацию (контакты, связи с другими контрагентами) от неподтверждённых пользователей

## User Stories

### US-R009-1: Покупка расширенного профиля

* **As a** пользователь платформы
* **I want to** приобрести расширенный профиль
* **So that** скрыть конфиденциальную информацию от неподтверждённых контрагентов

**Acceptance Criteria:**

* **AC-R009-U1-1:**
    * **Given:** Пользователь в настройках профиля
    * **When:** Нажимает "Купить расширенный профиль"
    * **Then:** Показывается стоимость и возможности расширенного профиля

* **AC-R009-U1-2:**
    * **Given:** Пользователь оплатил расширенный профиль
    * **When:** Оплата успешна
    * **Then:** Профиль активирован, конфиденциальная информация скрыта

### US-R009-2: Скрытие контактов

* **As a** пользователь с расширенным профилем
* **I want to** скрыть контактную информацию от неподтверждённых пользователей
* **So that** избежать спама и нежелательных запросов

**Acceptance Criteria:**

* **AC-R009-U2-1:**
    * **Given:** Расширенный профиль активирован
    * **When:** Неподтверждённый пользователь пытается увидеть контакты
    * **Then:** Контакты скрыты, показано "Контакты доступны после подтверждения"

* **AC-R009-U2-2:**
    * **Given:** Расширенный профиль активирован
    * **When:** Подтверждённый контрагент (сделка состоялась) смотрит профиль
    * **Then:** Контакты видны

### US-R009-3: Скрытие связей

* **As a** пользователь с расширенным профилем
* **I want to** скрыть историю связей с другими контрагентами
* **So that** конкуренты не видели моих клиентов и поставщиков

**Acceptance Criteria:**

* **AC-R009-U3-1:**
    * **Given:** Расширенный профиль активирован
    * **When:** Другой пользователь смотрит профиль
    * **Then:** История сделок скрыта (или доступна только сводка без имён контрагентов)

* **AC-R009-U3-2:**
    * **Given:** Расширенный профиль активирован
    * **When:** Пользователь сам смотрит свой профиль
    * **Then:** Вся информация видна

### US-R009-4: Приоритет в поиске

* **As a** пользователь с расширенным профилем
* **I want to** иметь приоритет в результатах поиска
* **So that** мои объявления показывались выше

**Acceptance Criteria:**

* **AC-R009-U4-1:**
    * **Given:** Расширенный профиль активирован
    * **When:** Объявление опубликовано
    * **Then:** Объявление получает приоритет в сортировке (выше обычных)

## System Constraints

| Constraint | Value | Notes |
|------------|-------|-------|
| Latency | < 500 ms | Время переключения профиля |
| Availability | 99% | Доступность сервиса |
| Subscription | 1/3/6/12 months | Периоды подписки |

## Out of Scope

- Полное анонимное присутствие (скрытие имени компании)
- Скрытие от платформы (администрации)
- Торговля расширенными профилями на вторичном рынке
