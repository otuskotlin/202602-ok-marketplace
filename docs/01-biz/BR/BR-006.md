## Business Value

Контрагенты могут обсуждать детали сделки (цену, доставку, условия) через встроенный чат, не покидая платформу

## User Stories

### US-R006-1: Начало чата с контрагентом

* **As a** пользователь платформы
* **I want to** начать чат с контрагентом из объявления
* **So that** я мог обсудить детали сделки

**Acceptance Criteria:**

* **AC-R006-U1-1:**
    * **Given:** Пользователь на странице объявления
    * **When:** Нажимает кнопку "Написать"
    * **Then:** Открывается чат с контрагентом, создаётся новый диалог

* **AC-R006-U1-2:**
    * **Given:** Пользователь уже имеет чат с контрагентом
    * **When:** Нажимает "Написать" из нового объявления
    * **Then:** Открывается существующий диалог с историей переписки

### US-R006-2: Отправка и получение сообщений

* **As a** пользователь платформы
* **I want to** отправлять и получать текстовые сообщения в чате
* **So that** я мог вести переписку с контрагентом

**Acceptance Criteria:**

* **AC-R006-U2-1:**
    * **Given:** Пользователь в чате
    * **When:** Вводит текст и нажимает "Отправить"
    * **Then:** Сообщение появляется в чате, отправляется контрагенту

* **AC-R006-U2-2:**
    * **Given:** Контрагент отправил сообщение
    * **When:** У пользователя открыт чат
    * **Then:** Сообщение появляется в реальном времени (или при обновлении)

* **AC-R006-U2-3:**
    * **Given:** Пользователь получает новое сообщение
    * **When:** Пользователь не в чате
    * **Then:** Приходит уведомление (email / push)

### US-R006-3: Вложения в чате

* **As a** пользователь платформы
* **I want to** прикреплять файлы к сообщениям
* **So that** я мог отправить технические спецификации, коммерческие предложения

**Acceptance Criteria:**

* **AC-R006-U3-1:**
    * **Given:** Пользователь в чате
    * **When:** Нажимает "Прикрепить файл" и выбирает файл
    * **Then:** Файл загружается и прикрепляется к сообщению

* **AC-R006-U3-2:**
    * **Given:** Пользователь получил сообщение с вложением
    * **When:** Нажимает на вложение
    * **Then:** Файл скачивается или открывается для просмотра
