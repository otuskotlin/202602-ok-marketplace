## Business Value

Пользователь может зарегистрироваться на платформе и начать использовать её для поиска контрагентов

## User Stories

### US-R001-1: Регистрация нового пользователя

* **As a** новый пользователь (продавец или покупатель)
* **I want to** зарегистрироваться на платформе
* **So that** я мог начать использовать платформу

**Acceptance Criteria:**

* **AC-R001-U1-1:**
    * **Given:** Пользователь открывает страницу регистрации
    * **When:** Вводит email, пароль, выбирает роль (продавец/покупатель)
    * **Then:** Система создаёт аккаунт и отправляет email для верификации

* **AC-R001-U1-2:**
    * **Given:** Пользователь получил email для верификации
    * **When:** Переходит по ссылке в email
    * **Then:** Аккаунт подтверждён, пользователь может войти

* **AC-R001-U1-3:**
    * **Given:** Незарегистрированный пользователь
    * **When:** Пытается зарегистрироваться с уже существующим email
    * **Then:** Система показывает ошибку "Email уже используется"

## System Constraints

| Constraint | Value | Notes |
|------------|-------|-------|
| Latency | < 2000 ms | Время отклика регистрации |
| Availability | 99% | Доступность сервиса |

## Out of Scope

- Авторизация через социальные сети (Google, Yandex)
- Двухфакторная аутентификация
- Регистрация юридических лиц с проверкой документов
