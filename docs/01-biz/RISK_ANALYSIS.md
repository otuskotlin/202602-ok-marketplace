## Категории рисков

### Рыночные риски

- **R1**: Недостаточная ликвидность платформы
- **R2**: Конкуренция с крупными маркетплейсами
- **R3**: Экономический спад в промышленности
- **R4**: Сезонные колебания спроса

### Операционные риски

- **R5**: Мошенничество контрагентов
- **R6**: Низкая конверсия регистраций
- **R7**: Отток пользователей
- **R8**: Неэффективная поддержка клиентов

### Технические риски

- **R9**: Сбой системы и недоступность
- **R10**: Утечка данных
- **R11**: Проблемы с производительностью поиска
- **R12**: Интеграция с ERP работает некорректно

### Регуляторные риски

- **R13**: Изменение законодательства
- **R14**: Блокировка в регионах
- **R15**: Таможенные ограничения для международных сделок
