## Business Value

Платформа анализирует статистику спроса и предложения по категориям компонентов, выявляя дефицитные и избыточные позиции, и предоставляет insights пользователям

## User Stories

### US-R007-1: Просмотр аналитики по категориям

* **As a** пользователь платформы
* **I want to** видеть аналитику спроса и предложения по категориям компонентов
* **So that** я мог определить перспективные позиции для продажи или дефицитные для закупки

**Acceptance Criteria:**

* **AC-R007-U1-1:**
    * **Given:** Пользователь на главной странице или в разделе аналитики
    * **When:** Открывает дашборд аналитики
    * **Then:** Видит графики: количество объявлений о продаже vs. покупке по категориям

* **AC-R007-U1-2:**
    * **Given:** Пользователь в дашборде аналитики
    * **When:** Выбирает категорию (например, "Подшипники")
    * **Then:** Видит детализацию по этой категории: динамика за N месяцев, средние цены

### US-R007-2: Уведомления о дефиците

* **As a** продавец
* **I want to** получать уведомления, когда по моим категориям появляется дефицит
* **So that** я мог быстро среагировать и разместить предложение

**Acceptance Criteria:**

* **AC-R007-U2-1:**
    * **Given:** Пользователь настроил уведомления о дефиците
    * **When:** По выбранной категории спрос превышает предложение
    * **Then:** Пользователь получает уведомление (email / push / в приложении)

* **AC-R007-U2-2:**
    * **Given:** Пользователь получил уведомление о дефиците
    * **When:** Переходит по ссылке из уведомления
    * **Then:** Видит объявления о покупке в этой категории

### US-R007-3: Отчёт по рыночным трендам

* **As a** пользователь платформы
* **I want to** получать регулярные отчёты о трендах на рынке
* **So that** я мог принимать обоснованные бизнес-решения

**Acceptance Criteria:**

* **AC-R007-U3-1:**
    * **Given:** Пользователь подписан на рассылку аналитики
    * **When:** Система формирует еженедельный/ежемесячный отчёт
    * **Then:** Пользователь получает email с ключевыми метриками и трендами

## Out of Scope

- Прогнозирование цен с использованием ML
- Интеграция с внешними источниками данных (Rosstat, UN)
- Экспорт данных в BI-системы
