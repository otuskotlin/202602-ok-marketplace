## Business Value

Продавец может разместить объявление о продаже компонентов, чтобы покупатели могли его найти

## User Stories

### US-R002-1: Создание объявления о продаже

* **As a** продавец (дистрибьютор, производитель)
* **I want to** разместить объявление о продаже компонентов
* **So that** покупатели могут найти мои товары

**Acceptance Criteria:**

* **AC-R002-U1-1:**
    * **Given:** Авторизованный пользователь с ролью "продавец"
    * **When:** Заполняет форму объявления (название, описание, цена, количество, категория)
    * **Then:** Объявление создано и доступно для поиска

* **AC-R002-U1-2:**
    * **Given:** Продавец создал объявление
    * **When:** Добавляет характеристики товара (артикул, бренд, спецификация)
    * **Then:** Характеристики отображаются в объявлении

* **AC-R002-U1-3:**
    * **Given:** Продавец создал объявление
    * **When:** Указывает условия поставки (самовывоз, доставка, сроки)
    * **Then:** Условия отображаются в объявлении

### US-R002-2: Редактирование объявления

* **As a** продавец
* **I want to** отредактировать созданное объявление
* **So that** обновить информацию о товаре

**Acceptance Criteria:**

* **AC-R002-U2-1:**
    * **Given:** Продавец имеет активное объявление
    * **When:** Изменяет цену или количество
    * **Then:** Изменения сохранены и отображаются

### US-R002-3: Удаление объявления

* **As a** продавец
* **I want to** удалить объявление
* **So that** оно больше не отображается в поиске

**Acceptance Criteria:**

* **AC-R002-U3-1:**
    * **Given:** Продавец имеет активное объявление
    * **When:** Нажимает кнопку "Удалить"
    * **Then:** Объявление удалено (скрыто) из поиска

## System Constraints

| Constraint | Value | Notes |
|------------|-------|-------|
| Latency | < 1000 ms | Время сохранения объявления |
| Max image size | 5 MB | Ограничение на загрузку изображений |

## Out of Scope

- Автоматическая модерация объявлений
- Продвижение объявлений (топ в поиске)
- Пакетная загрузка объявлений (bulk)
